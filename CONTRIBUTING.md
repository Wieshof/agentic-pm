# Contributing

🇬🇧 English · 🇩🇪 [Deutsch](CONTRIBUTING.de.md)

Thanks for your interest in agentic-pm!

## How we work

- **Issues first.** Open an issue (feature, bug or design question) before starting larger work.
- **Milestones = roadmap phases.** See [docs/roadmap.md](docs/roadmap.md).
- **Architecture decisions** are recorded as ADRs in [`docs/adr/`](docs/adr/), using [`0000-template.md`](docs/adr/0000-template.md).
- **Small PRs** with a clear description and a link to the issue.

## Labels

| Label | Meaning |
|-------|---------|
| `layer:adapter` / `layer:engine` / `layer:interface` | Architecture tier |
| `loop:*` | One of the five agentic loops |
| `guardrails` | Permissions, privacy, audit |
| `design` | Needs discussion / ADR |

## Code of conduct

Be kind, be constructive, assume good intent.
